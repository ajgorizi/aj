# Amirsalar: single, serious about marriage

A one-page personal site for the flyer QR code.

Files: index.html, hero.jpg, me.jpg, park.jpg (keep them together in the main folder).

## Put it online with GitHub Pages
1. Go to github.com and click New repository.
2. Name it `hello` and make it Public. Click Create repository.
3. Click "uploading an existing file", drag in index.html and all 3 photos (hero.jpg, me.jpg, park.jpg), then click Commit changes.
4. Go to Settings > Pages. Under Source pick "Deploy from a branch", choose `main` and `/ (root)`, click Save.
5. Wait 1-2 minutes. Your page will be at https://ajgorizi.github.io/hello/

If you use a different repo name, the address changes and the QR code needs to be remade.

The page has a "noindex" tag so it won't show up when people Google your name.
